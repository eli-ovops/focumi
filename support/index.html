FOCUMI

Support

For help with Focumi, use our public support channel: Open a support request.

Support requests are public GitHub Issues. Please do not include personal information, screenshots containing private content, or the names of apps you selected in Screen Time.

Before you write

Focumi’s app-limiting feature requires Apple Family Controls permission. You can update the selected apps or categories, end a focus session, or remove the feature’s settings from Focumi.
